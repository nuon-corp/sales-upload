# 매출 업로드 변환기 (웹)

채널별 매출 정산 엑셀을 아마란스 **데이터 업로드 양식**(매출 / 부가세 / 광고 / 수수료)으로 바꿔 주는 웹 페이지입니다.
엑셀 파일은 사용하는 사람의 브라우저 안에서만 처리되고, 서버로 전송되거나 저장되지 않습니다.

## 사용법
1. 사이트 주소로 접속 (처음 열 때 변환 엔진을 받느라 10초 정도 걸림)
2. 채널 정산 엑셀을 끌어다 놓기 (.xlsx / .xls / .csv, 여러 개 가능, 파일명 무관)
   - **채널(계정)마다 원본은 한 파일로**: 정산·부가세 자료가 나뉜 채널(11번가, 카카오, 토스 등)은 부가세 자료를 정산 파일에 시트로 복사해 넣기 (시트 이름 무관)
   - 카카오처럼 계정이 여러 개면 계정마다 한 파일 (예: `카카오(살림백서).xlsx`, `카카오(아우페).xlsx`)
3. [변환] → 표의 합계를 채널 정산서와 대조 → [받기] 또는 [결과 전체 받기 (zip)]
   - 결과 파일명 = **원본 파일명 + `_변환`** (예: `카카오(살림백서).xlsx` → `카카오(살림백서)_변환.xlsx`)

상태: 완료(초록) · 완료·확인필요(노랑, 안내 문구 확인) · 건너뜀(등록 안 된 채널) · 오류(채널 엑셀 양식이 바뀜 → 전산 담당자에게)

## 원본에 없는 금액 넣기 ('추가' 시트)
서버이용료처럼 원본 데이터에 없는 금액은 원본 파일에 **'추가' 시트**를 만들어 적으면 업로드 파일에 한 줄씩 들어갑니다.
`추가시트_양식.xlsx`의 '추가' 시트를 원본 파일에 복사해서 쓰세요.

| 구분 | 상품명 | 금액 | 상품코드(선택) | 과세구분(선택) |
|---|---|---|---|---|
| 수수료 | 11번가 서버이용료 | 77000 | | |

- 구분: 매출 / 수수료 / 광고, 금액: 부가세 포함, 과세구분은 매출일 때만(기본 14)
- 자동으로 들어가는 금액은 없음 — 11번가 서버이용료(77,000원)도 나간 달마다 '추가' 시트에 적기

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 |
| `convert_sales.py` | **변환 규칙 (채널별 처리 방식은 전부 여기)** |
| `데이터 업로드 양식.xlsx` | 아마란스 업로드 양식 (1~3행 유지, 4행부터 데이터) |
| `추가시트_양식.xlsx` | 원본에 없는 금액을 넣을 때 쓰는 '추가' 시트 양식 |
| `채널설정.xlsx` | 단순한 표 형태 채널을 코드 없이 추가할 때 (선택) |
| `wheels/` | 엑셀을 읽고 쓰는 라이브러리 (openpyxl, xlrd) — 건드리지 않기 |

## 규칙 고치는 법

### 간단한 수정 (상수 값 하나 등)
1. GitHub에서 `convert_sales.py` 열기 → 연필 아이콘(Edit)
2. 수정 후 맨 위 `RULES_VERSION` 날짜도 바꾸기 (화면 제목 옆에 표시돼서 어떤 규칙으로 변환했는지 알 수 있음)
3. Commit changes → 1~2분 뒤 반영 (사용자는 새로고침만 하면 됨)

### 큰 수정 / 채널 추가 — 먼저 테스트하고 반영
경영지원팀이 쓰는 중에 덜 고친 규칙이 반영되지 않도록, 테스트 파일로 먼저 확인합니다.
1. 수정한 규칙을 `convert_sales_test.py` 이름으로 업로드 (기존 `convert_sales.py`는 그대로)
2. `사이트주소/?rules=convert_sales_test.py` 로 접속 → 노란 "테스트 규칙" 띠가 보이는지 확인 → 원본 넣고 결과 확인
3. 문제없으면 `convert_sales_test.py` 내용을 `convert_sales.py`에 덮어쓰고 Commit → 테스트 파일은 삭제

잘못 반영됐으면 `convert_sales.py` → History에서 이전 버전으로 되돌리면 됩니다.

자주 바꾸는 값은 파일 위쪽 상수에 모여 있습니다. 예) `ST11_ADJ_TAX`(11번가 매출조정 과세구분), `HOMESHOP_TAX`(홈쇼핑 과세구분)
